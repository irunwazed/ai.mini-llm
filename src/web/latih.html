2 Siapkan data (tokenisasi)

Data mentah diubah menjadi token dan disimpan sebagai DATASET di data/siap/<nama>/. Training (langkah 3) hanya membaca dataset ini. Untuk melanjutkan atau fine-tune model yang sudah ada, pakai tokenizer dari model itu — id token harus berarti potongan kata yang sama.

Latih di server (mis. packet.ai, lewat SSH)

Training proyek ini memakai CPU (worker thread), GPU/RTX tidak dipakai, jadi pilih instance dengan banyak core CPU. Data dikirim lewat Google Drive (jika sudah login) atau scp, training berjalan di tmux (tetap jalan walau laptop mati), lalu model dikirim balik. Pengaturan & peluncuran dari terminal karena butuh kunci SSH Anda.
bun run server -- --atur ubuntu@<IP> --port <port>      (alamat SSH dari dashboard packet.ai)
bun run server -- --siapkan                               (pasang bun, kirim kode, cek CPU/RAM)
bun run server -- --latih -- --dataset obrolan-v1 --from wiki2 --name chat3 --steps 1500
bun run server -- --log chat3 --ikuti        bun run server -- --hentikan chat3
bun run server -- --ambil chat3                            (model ke laptop, lalu pilih di halaman chat)
