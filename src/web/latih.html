Peta data — disimpan di mana?

Setiap langkah membaca dari satu tempat dan menulis ke tempat berikutnya: ① ambil → data mentah · ② siapkan → data/siap/<dataset> · ③ latih → model · ④ evaluasi. Tabel ini dibaca langsung dari disk.
File yang sedang ditulis (diubah < 2 menit lalu) otomatis dilewati.

1 Ambil data

Mengumpulkan data MENTAH. Semua bisa dijalankan ulang: yang sudah diunduh dilewati.

Unduh Wikipedia Indonesia

→ data/mentah/wikipedia/wiki-id.txt

Unduh dokumen aturan JDIH BKN

→ documents/jdih/

Buat data obrolan (percakapan latih)

→ data/mentah/obrolan/chat-id.jsonl

Buat data GPT pembaca

→ data/mentah/pembaca/reader-id.jsonl

Upload file

Seret file ke sini, atau

2 Siapkan data (tokenisasi)

Data mentah diubah menjadi token dan disimpan sebagai DATASET di data/siap/<nama>/. Training (langkah 3) hanya membaca dataset ini. Untuk melanjutkan atau fine-tune model yang sudah ada, pakai tokenizer dari model itu — id token harus berarti potongan kata yang sama.

3 Latih

Model GPT membaca dataset dari langkah 2. Ada tiga cara: model baru (mulai dari nol), lanjutkan (model yang sama dilatih lagi dengan dataset baru — riwayat dataset dicatat di model), fine-tune (mulai dari bobot model lain, disimpan sebagai model baru).
